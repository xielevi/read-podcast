# 1.0 发布验收矩阵

每次候选版本（RC）都要用**最终发布物**（签名公证后的 DMG，不是本地 `--dev` 构建）
完整跑一遍。有失败项就修完后原样重跑整张表，不做「只补跑失败项」。

记录方式：复制本文件到 Issue 或 Release 讨论里逐项打勾，注明机器、系统版本、
RC 版本号与构建 commit。

## 1. 干净 Apple Silicon Mac，macOS 13.5（最低支持版本）

前提：未预装 Homebrew、ffmpeg、Python、uv。

- [ ] 下载 DMG，SHA256 与 Release 中公布的一致
- [ ] 拖入 Applications，**直接双击打开**（不需要右键→打开，不需要改安全设置）
- [ ] 首次模型下载完成
- [ ] 填入 AI Key，连接测试通过
- [ ] 订阅一个真实 RSS
- [ ] 完整跑通：下载音频 → MLX 转录 → AI 精修 → 阅读/下载 Markdown
- [ ] 上传一个本地音频，再完整处理一次
- [ ] 退出并重启：订阅、稿件、阅读状态、任务记录都还在

## 2. 当前主流 macOS 版本

- [ ] 重复第 1 节的安装与完整主流程
- [ ] WKWebView 内下载 Markdown 正常
- [ ] 外部链接在系统浏览器打开
- [ ] 首次模型下载正常
- [ ] 退出应用后，转录后端等子进程全部退出（`ps` 确认无残留）

## 3. v0.2.0 DMG → 本 RC 升级

升级前先造出真实数据：订阅、历史任务、已读状态、稿件、API Key、OAuth 凭据。

- [ ] 直接替换 `/Applications/Read Podcast.app`
- [ ] `~/Library/Application Support/Read Podcast` 下的全部数据继续可用
- [ ] 订阅、稿件、已读状态、任务记录逐项核对无丢失
- [ ] API Key 与 OAuth 凭据无需重填

## 4. 源码安装 → DMG 迁移

- [ ] 把仓库里的 `config/`、`workspace/` 迁入 Application Support
- [ ] 迁移后订阅与历史稿件能正常打开
- [ ] **重点**：数据库里存过绝对 `output_path` 的历史记录仍能定位到文件
- [ ] 密钥从 `.env` / `config/secrets.env` 正确带过去

## 5. 回滚

- [ ] 备份 1.0 数据目录后换回 v0.2.0 App
- [ ] 旧版能启动并读取数据；若迁移已造成不兼容，则验证从升级前快照恢复成功
- [ ] Release Notes 里「回滚 App」与「恢复数据」两步分别写清楚且可照做

## 6. 中断与异常恢复

- [ ] 转录过程中强制退出，重启后任务标记为中断且可重试
- [ ] 断网时给出可执行的提示
- [ ] API Key 错误时给出可执行的提示
- [ ] 磁盘空间不足时给出可执行的提示
- [ ] 「帮助 → 打开运行日志」能拿到日志，且日志中不含明文 Key

## 发布判定

以上六节全部通过，且 `scripts/check_release.py --dist dist` 通过，才可以把 RC
提升为正式版。
