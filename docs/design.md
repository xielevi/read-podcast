# Read Podcast 产品与界面规范

## 产品心智模型

Read Podcast 帮用户完成一条清晰路径：**选择声音 → 生成稿件 → 阅读**，并可以把已生成的稿件公开分享。
产出是完整长文稿而不是摘要，界面语言围绕“稿件”而不是“转录”组织。

用户任务优先。信息架构和交互可以调整，后端业务契约保持稳定。界面使用“订阅、导入、稿件、生成、整理、阅读”等产品语言；底层 Workflow、对象存储、转写服务、模型供应商和持久化实现不进入日常界面。

健康状态默认沉默。只有服务异常或任务失败时才需要用户注意。所有生成进度来自 `progress_pct`、`stage`、`message`，不制造 ETA 或伪进度。

## 信息架构

顶层只有三个等宽、单行工作区：

| 工作区 | 图标 | 用户任务 |
|---|---|---|
| 订阅 | `rss` | 选择节目和单集，生成稿件 |
| 导入 | `upload` | 上传自己的音频，选择稿件风格 |
| 稿件 | `book-open` | 查找、阅读和管理已经生成的稿件 |

全局层只保留品牌、处理中任务入口和设置。任务面板属于全局层，单集详情只描述当前单集。

## 两种能力级别

同一个工作区有两种能力级别，布局与信息架构完全相同（架构约束见 `docs/ARCHITECTURE.md`）：

| | 公开浏览（`/`） | 主人控制（`/manage`） |
|---|---|---|
| 谁 | 任何访客 | 通过 Cloudflare Access 的主人 |
| 顶栏 | “外观”、“登录管理”、设置入口 | “处理中”任务入口、设置 |
| 单集状态 | 只有“可阅读”与“未生成”，不显示过滤标签 | 未生成 / 生成中 / 待读 / 已读 / 失败，带过滤标签 |
| 阅读器 | 大纲、概念、排版、下载 | 另有阅读进度、已读切换、自动标记已读 |
| 偏好 | 存在访客浏览器 `localStorage`，初始值取主人的云端默认 | 存在 D1，跨设备同步 |

公开浏览保留控制入口（订阅、导入、生成稿件、设置等），点击后带意图跳转到 `/manage`，由 Access 完成登录；
没有登录弹窗。公开浏览不展示任务进度、失败信息或已读状态。

## 页面布局

### 订阅

桌面采用节目列表、单集列表、单集详情三列。左栏包含全部订阅、节目列表和添加订阅；中栏包含搜索、状态过滤和单集列表；右栏展示当前单集的标题、节目、日期、时长、简介、状态、进度和主动作。

中屏保留节目与单集两列，详情使用 drawer。手机使用底部导航，详情使用 sheet 或全屏面板。

### 导入

聚焦单列，最大内容宽度 720px。顺序为上传区域、稿件风格、高级说明和生成稿件。高级说明默认收起，不展示只读 prompt 墙。上传与生成是两个独立阶段。

### 稿件

使用宽列表。标题或节目搜索与“全部 / 待读 / 已读”过滤置于顶部。卡片的一级动作是阅读，下载 Markdown 为直接动作。

### 阅读

沉浸式全屏严肃长篇阅读。

- **双端适配与信息架构**：
  - **桌面端**：顶部工具栏包含大纲侧栏开关、排版与主题外观（`Aa` 弹出面板）、下载 Markdown、主人态直接已读切换与关闭；大纲与关键概念以左侧栏展示；主人态下方细线显示阅读进度。
  - **移动端**：顶部克制页头在向下滚动时折叠、向上滚动浮现；底部常驻阅读栏提供“目录”、“进度”（仅主人态）、“排版”触点，均以底部弹层（Bottom Sheet）展开。
  - **正文呈现**：稿件开头模型生成的“节目大纲与时间线”只在阅读视图中隐藏（与左侧大纲重复），存储的 Markdown 与下载内容保持原样。
  - **低频操作定位**：下载 Markdown 与已读标记均为明确的直接操作，不使用省略号菜单，也不挤入排版设置。
- **主题系统**：
  - 支持“跟随应用（默认）”、“杏仁纸张”、“暖阳羊皮”、“护眼绿”、“极夜黑”共 5 种主题。
  - 所有阅读器 Chrome 控件（页头、底栏、Popovers、Bottom Sheets、大纲目录、进度控制）严格采用 `--reader-*` 变量隔离，杜绝暗色模式下的对比度与字色反差问题。
- **排版系统**：
  - 提供“文雅经典”（仿宋/宋体+衬线）与“现代清晰”（系统无衬线）两种字体预设；
  - 提供字号（A- / A+）与行距（紧凑/舒适/宽松）调节；桌面正文采用单一宽版阅读宽度并受可用空间约束；
  - 阅读偏好按能力级别持久化：主人态存 D1、跨设备同步；公开浏览存访客本地 `localStorage`。主人态滚动到底部自动标记已读。

## 用户流程

### 从订阅生成

1. 在订阅中选择节目和单集。
2. 点击“生成稿件”。
3. 列表、详情和全局任务面板同步显示真实进度。
4. 完成后状态变为“待读”，主动作变为“阅读”。

### 从音频生成

1. 选择或拖入音频。
2. 上传阶段显示“正在上传 N%”。
3. 选择稿件风格，可选填高级说明。
4. 点击“生成稿件”，上传状态结束并进入四阶段生成进度。

### 添加订阅

单一输入框接受关键词或 RSS URL。关键词执行节目搜索，URL 自动识别。搜索结果行直接提供“订阅”，不再经过选中与二次确认。

## 状态与进度

### 用户状态

- 未生成
- 生成中 · N%
- 待读
- 已读
- 失败

公开浏览只显示“可阅读”与“未生成”。

### 生成阶段

| 内部阶段 | 用户阶段 |
|---|---|
| `queued`, `resolving`, `downloading` | 获取音频 |
| `transcribing` | 转写 |
| `refining` | 整理 |
| `finalizing`, `done`, `success` | 保存 |

列表显示状态、百分比和细进度条；详情显示四阶段轨道与 `message`；全局面板显示所有运行任务。失败文案为“生成失败 / AI 整理暂时没有完成”，动作是“重试 / 移除”。

| 避免 | 使用 |

供应商、数据库、部署工具、Secret 名称和内部配置键不得出现在日常 UI 文案中。

## 按钮与图标

线框 SVG 统一使用 24×24 viewBox、圆角端点和一致描边。主要映射：订阅 `rss`、导入 `upload`、稿件/阅读 `book-open`、生成稿件 `document`、重新生成 `rotate-cw`、任务 `activity`、设置 `sliders`、停止 `x-circle`、下载 `download`、成功 `check-circle`、失败 `alert-circle`。

按钮只分四级：

- Primary：生成稿件、订阅、保存
- Secondary：阅读、测试、重试
- Ghost：取消、停止、返回、移除
- Icon：设置、搜索、关闭

Danger 只用于不可逆破坏性操作。

## 视觉 token

颜色、间距、圆角、阴影、字体和动效只引用 `public/app.css` 的 token。浅色与暗色共享语义色；正文阅读主题与应用外观分离。界面以内容和层级为主，图标只帮助扫描，不承担装饰。

### 颜色系统

基调是暖调纸面：象牙白底、墨色文字、实色表面、细边框，暗色是同一色相的暖炭灰。不使用背景光晕、玻璃模糊、渐变或霓虹色；高饱和颜色只在需要强调或警示时出现。

| 角色 | token | 浅色 | 深色 | 职责 |
|---|---|---|---|---|
| 背景 | `--bg-base` | `#faf9f5` | `#262624` | 页面与页头 |
| 表面 | `--surface` / `--surface-strong` | `#ffffff` | `#30302e` | 卡片、抽屉、弹层 |
| 凹陷 | `--surface-weak` | `#f0eee6` | `#1f1e1d` | 分段控件轨道、进度轨、空状态、hover 底 |
| 选中 | `--selected` | 墨色 6% | 象牙 7% | 列表选中与悬停的中性填充 |
| 文字 | `--text-primary/secondary/tertiary` | `#1f1e1d` / `#5e5d59` / `#6f6e69` | `#f5f4ee` / `#c2c0b6` / `#9c9a92` | 正文、说明、标签 |
| Primary | `--primary` / `--on-primary` | 墨色底 + 象牙字 | 象牙底 + 墨色字 | 普通主按钮（生成稿件、保存、重试） |
| Accent | `--accent` / `--accent-text` / `--accent-soft` | `#c96442` / `#a8512f` | `#d97757` / `#e39274` | 品牌陶土色：进行中（进度条、生成中、处理中）、焦点环、链接 |
| Success | `--success` / `--success-soft` | `#2f7348` | `#86c093` | 待读、已配置、已读切换 |
| Warning | `--warning` | `#935e0c` | `#dcaa55` | 警告提示 |
| Danger | `--danger` / `--on-danger` | `#b3362c` + 白字 | `#f0857a` + 墨字 | 仅限破坏性操作（删除确认、停止悬停）与失败状态 |
| Info | `--info` | `#3d6689` | `#93b4d4` | 信息提示 |

规则：

- **选中与导航用中性色，不用品牌色**：tab、过滤、侧栏与单集选中都用墨色文字，加 `--selected` 填充或墨色指示条。
- **Accent 不做按钮底色**：陶土色只表达“进行中”和“可跳转”，同一屏里只应在少数位置出现。
- **Danger 与 Accent 严格分开**：陶土色偏橙、危险色偏红，危险色不承担品牌或普通主操作；失败同时配文字。
- **已读是安静状态**：“待读”用 success，“已读”用中性灰，失败用 danger。
- 所有文字色在对应背景、表面与凹陷层上的对比度 ≥ 4.4:1（主要文字 ≥ 4.5:1）；`prefers-contrast: more` 进一步加深文字与边框。
- 阅读器主题（`--reader-*`）自成一组：纸面与暖阳沿用陶土色链接，护眼绿用墨绿，极夜黑与应用暗色同底；标题与代码使用正文墨色。

触控目标至少 44×44px，正文宽度控制在舒适阅读范围，进度颜色在浅色与暗色背景上都满足可辨识度。

## 响应式

- `>1180px`：订阅三列；导入聚焦单列；稿件宽列表。
- `781–1180px`：订阅两列，详情 drawer；导入和稿件使用主内容区。
- `≤780px`：底部导航“订阅 / 导入 / 稿件”；详情 sheet；阅读器全屏。

三个顶层导航标签始终等宽、单行，任何断点都不得折行。

## 可访问性

- 所有图标按钮提供 `aria-label`；装饰图标使用 `aria-hidden="true"`。
- tab、dialog、progressbar 使用对应语义与状态属性。
- 键盘可完成导航、打开详情、上传、生成、阅读和关闭面板。
- `:focus-visible` 始终清晰可见。
- `prefers-reduced-motion` 下取消非必要动画和顺滑滚动。
- 界面始终使用实色表面，不依赖透明与模糊，`prefers-reduced-transparency` 无需单独降级。
- 状态不能只依赖颜色，必须同时有文字或图形标记。
